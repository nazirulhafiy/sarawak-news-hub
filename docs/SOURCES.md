# Reference photos

Wikimedia Commons photos used while drawing the Kuching riverfront. No photo is published.

Three shapes were traced, and About credits those three:

- ref2, the DUN
- ref13, the Darul Hana pylon shape
- ref17, the Santubong silhouette

The rest were used only to check general proportions. The tambang photos (ref9, John Mason, and ref12, Tnunong) are omitted because the boat is not in the drawing.
